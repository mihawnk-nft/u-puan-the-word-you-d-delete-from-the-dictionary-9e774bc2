Entry for the [make.fun competition "The Word You'd Delete From the Dictionary"](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

## What it does

`main.py` (pure Python standard library, no dependencies) writes one word to `/output/entry.txt`: the single word this entry would erase from the dictionary forever.

**The word: `irregardless`**

Why this pick: it is a real, instantly recognised dictionary word — and the one that should never have been in the dictionary at all. "ir-" plus "-less" stacked into a double negative that means exactly the same as "regardless". Deleting it is the dictionary correcting its own mistake. The joke lands the moment the word is gone, comes from the word itself, and leaves everyone who says it with no choice but to finally just say "regardless".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Output: `irregardless` (12 characters, one word, valid under the competition gate of 1–77 UTF-8 characters).
